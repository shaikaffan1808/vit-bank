# Vit Bank

A small HTML, CSS, and JavaScript project for Visual Studio Code. No Node.js install or build step is required.

## Run it
1. Extract this ZIP file.
2. Open the `vit-bank-vscode` folder in Visual Studio Code.
3. Install the recommended **Live Server** extension.
4. Open `index.html` and select **Go Live** in the VS Code status bar.

Use the **Create account** button on the login screen to make a local account. Each account and its practice activity are saved separately in that browser. Wallet additions are local only and do not process payments.
